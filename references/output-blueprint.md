## §5 第 5 步 · 方案定制引擎

**输入**:`{ 机会类型(主+辅), 证据深度(L1/L2/L3), 三层素材 }` → **输出三件套**。

**证据深度定精细度**:
- 只到 L1 / L2 → **方向级**(内容角度 + 钩子方向)
- 进 L3 → **脚本级**(钩子 / 演示动作 / CTA 可直接拍)

### 三件套

#### ① 内容方向(优先 ≥ 3 + 不建议)

每个方向给:**角度 + 钩子方向**(+ L3 则补脚本骨架:钩子/演示/CTA)。

- **不建议方向**(并说明为什么):同质化严重 / 播放高但商业弱 / 依赖大达人或大制作 / 合规风险。
- **物料语言 = 目标市场原文**(见末尾「输出语言」)。

#### ② 首轮达人画像(内容参考组 + 首轮合作组)

- **内容参考组**(3~5 个):可学其内容的达人。给:粉丝量 / 内容风格 / **为什么值得学**(挂依据)。
- **首轮合作组**:**⭐ 硬约束——只列有联系方式(邮箱)的**(不盲假设能联系上)。给:达人 / 粉丝 / **契合度评分 + 理由** / 联系方式。
- 匹配评分由 skill 计算**并展示依据**(数据规范 8 条 ⑧:搜索只是召回,评分是 skill 算的)。

#### ③ 最小测试计划(按机会类型自适应配比,不一刀切)

- **记录指标**:播放 / 互动 / 点击 / 成交。
- **判据**:写清**放大 / 修改 / 停止**的触发条件(如「单视频播放 > X 且互动率 > Y% → 放大该角度」)。

### 机会类型 × 方案侧重(主配比表)

| 机会类型 | 内容方向 | 达人 | 测试计划 |
|---------|--------|------|--------|
| **品类红利型** | 宽口径多角度 | 两组并重,抢占位 | 宽铺:3-5 角度 × 5 达人 × 7-10 天,**重覆盖** |
| **差异化型** | 聚焦差异点(1-2 角) | 找契合差异点的 | 聚焦:1-2 角度 × 3 达人 × 10-14 天,**重验证** |
| **内容驱动型** | 重钩子,多版本 | 偏内容参考 | 迭代:1-2 角度 × 多版本 × 7-14 天,**重找爆款** |
| **达人撬动型** | 给可套框架 | 首轮合作组为主角 | 达人筛:少角度 × 多达人 × 7-10 天,**重找对人** |

## 报告落盘

第 5 步跑完,把上面 5 部分报告写成一个 markdown 文件,落到 **skill 目录下的 `output/`**。

- **路径**:`output/报告文件名.md`(相对 skill 根目录)。用户指定别处则听用户的。
- **命名格式**:`YYYY-MM-DD_[市场]_[品名关键词]_[档位].md`
  - **日期**:跑报告当天(ISO `YYYY-MM-DD`,文件名自然排序,最新在后)。
  - **市场**:目标市场码(US / GB / ID / TH / VN / …)。
  - **品名关键词**:品牌 + 品类核心词,**≤20 字**,提炼自标题、不照搬长标题;空格用 `-`;避开文件名非法字符(`/ \ : * ? " < > |`)。
  - **档位**:值得测试 / 有条件测试 / 证据不足(与报告【1】档位一致)。
  - **示例**:`2026-08-07_US_Laura-Geller-粉底_值得测试.md`
- **文件头**(正文最上方,5 部分报告之前)补一行元信息:
  ```
  > 生成时间:YYYY-MM-DD HH:MM ｜ 市场:[region] ｜ 证据深度:L1/L2/L3 ｜ 机会类型:[型] ｜ 召回可信度:[高/中/低]
  ```
- **重测同名品**:不覆盖旧报告——文件名加 `-v2`/`-v3` 后缀(如 `...-值得测试-v2.md`),留对比。
- **零依赖手填场景同样落盘**:无论 MCP 自动取还是用户手填,结论都沉淀成报告;手填场景在文件头补「数据来源:用户手填」。

## 输出语言

- **物料**(内容方向的标题/钩子/脚本/CTA、达人合作邀约话术)= **目标市场原文**(US=英文,JP=日文,DE=德文…,按 region)。
- **报告解读**(分析/判断/建议/理由)= **中文**。

## 用户掌舵(再次强调)

方案是**建议不是命令**。参数(达人数量 / 测试周期 / 角度数)**可改**——给「为什么这么配」的依据(挂机会类型 + 证据),让用户能自己调。最终 go/no-go 在用户。
